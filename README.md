# Superstore Sales Analysis (SQL)

## Project Overview
A SQL project analyzing the Superstore dataset to understand sales trends, profit distribution, discounts, shipping modes, and customer segments using aggregate functions and subqueries.

## Dataset
The dataset used in this project was downloaded from Kaggle (Sample Superstore dataset).

## Tools Used
- MySQL
- MySQL Workbench

## Analysis Performed
- Sales analysis
- Profit analysis
- Discount analysis
- Shipping mode analysis
- Segment analysis
- Subquery-based insights
